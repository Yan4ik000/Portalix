# Тесты

Набор состоит из небольших JUnit-тестов логики мода и игровых сценариев на Fabric и NeoForge. Для запуска нужны Java 25 и Python 3. Команды выполняются из корня проекта.

## Запуск

| Команда | Что проверяет |
| --- | --- |
| `./gradlew :test` | Общая и клиентская логика без запуска игры |
| `./gradlew :testServer` | Серверные GameTest на обоих загрузчиках |
| `./gradlew :testClient` | Игровой клиент выбранного профиля |
| `./gradlew :testProfile` | Логика, сервер и клиент одного профиля |
| `./gradlew :testInfrastructure` | Работа запуска и проверки результатов |
| `./gradlew build` | Сборка, JUnit и состав выпускаемых JAR |

Профиль задаётся через `-PtestProfile`, по умолчанию используется `fabric-native-opengl`. Список профилей: `./gradlew :listTestProfiles`.

Отдельную игровую сцену можно выбрать через `-PclientTest`, серверную группу — через `-PserverTest`:

```sh
./gradlew :testClient -PtestProfile=fabric-sodium-iris-opengl -PclientTest=portal_views
./gradlew :testServer -PserverTest=carry
```

Все поддерживаемые графические профили с загрузкой собранных JAR:

```sh
python3 tests/test_matrix.py --packaged
```

Матрица включает native, Sodium и Sodium + Iris на OpenGL, а также native и Sodium на Vulkan для обоих загрузчиков. Iris-профили используют Complementary Unbound с настройками HIGH.

В сеансе Linux Wayland при зависании показа Xwayland-окна внутри GLFW можно выбрать нативный Wayland для текущего запуска:

```sh
JDK_JAVA_OPTIONS='-DMC_DEBUG_ENABLED=true -DMC_DEBUG_PREFER_WAYLAND=true' python3 tests/test_matrix.py --packaged
```

## Сценарии

Серверные группы: `placement`, `traversal`, `player_traversal`, `projectiles`, `combat`, `carry`, `chunks`, `content`. Они проверяют установку и сброс порталов, обычное движение, полёт и попадание снарядов, бой, перенос объектов, загрузку удалённого мира, сохранение сущностей, крафт и добычу.

Клиентские сцены:

| Сцена | Действия |
| --- | --- |
| `camera` | Первый и третий вид, движение через настенный и напольный портал |
| `portal_views` | Вид через портал, ориентация, прозрачные материалы и параллакс |
| `gun` | Экипировка вариантов пушки, основной и дополнительный выстрел, эффекты и сброс |
| `player_traversal` | Проход, прыжок и падение через порталы |
| `carry` | Захват, движение с объектом, отпускание и бросок |
| `combat` | Удары и защита через портал |
| `entity_traversal` | Движение предметов, существ и снарядов через портал |
| `vehicles` | Транспорт и пассажиры |
| `world_updates` | Изменения блоков, освещения и сущностей по другую сторону |
| `audio` | Позиционный звук, пауза, закрытие портала и остановка |
| `resources` | Перезагрузка ресурсов и отображение свежего изменения удалённого блока |
| `lifecycle` | Отключение и повторный вход в мир |

Сцены используют реальный клиент, обычные игровые действия и нативную физику. Проверки отображения работают со снимками фактического игрового окна; снимки сохраняются рядом с отчётом. Обычный прогон использует дальность 16 чанков. `-PtestDiagnostics=full` дополнительно сохраняет запись кадров для ручного просмотра.

Результаты находятся в `tests/build/reports/regression`, серверные отчёты — в каталогах сборки загрузчиков. Ошибки запуска, провал или пропуск выбранной сцены завершают проверку ошибкой.

## Производительность

Отдельный существующий маршрут измеряет время кадров во время выстрела, прохода в удалённую область, повторного посещения и обратного прохода через ту же пару:

```sh
./gradlew :benchmarkClient -PtestProfile=fabric-native-opengl
```

Отчёт сохраняется в `tests/build/reports/benchmarks`. По умолчанию используется дальность прорисовки 16 чанков; параметр `-PbenchmarkRenderDistance=32` увеличивает её до 32.
